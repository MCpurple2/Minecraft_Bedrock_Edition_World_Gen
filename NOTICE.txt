PE Worldgen: experimental PE 0.11.1 research port

The world customization GUI adapts the client-side layout, preset navigation,
and settings actions from Moderner Beta. These adaptations use the upstream MIT version. See LICENSES/Moderner-Beta-MIT.txt.
The Gradle wrapper launcher is from the Moderner Beta repository (Gradle's
Apache-2.0-licensed wrapper).

This project does not bundle the Minecraft Pocket Edition APK or native library.
See the core source and research notes for the actual reconstruction status.

Project license: Apache-2.0 for original contributions. See LICENSE.
The corresponding project source and Gradle build files for this release are
distributed in the source archive directory 'source/Build 2.4 IWBUMS/'.
