Bedrock Edition World Generator Build 3.13 · IWBUMS
Minecraft Java Edition 1.21.11 · Fabric

Build 3.13 在 Bedrock Exclusive Features Provider 新增 Use Legacy Clay blob。早期预设默认开启，0.9.5 起默认关闭；旧存档按版本恢复默认值。开关控制水中起点、替换沙子的旧式黏土团。早期关闭时保留原随机数消耗，后期手动开启时使用独立的随机状态副本。主界面的模组兼容设置移至 BEFP 下方，提供配置入口及右侧 JSON 编辑器。本版暂无兼容选项，JSON 接受空对象 {}，未知字段会提示无效。青花改用本次提供的贴图。

Build 3.12 修复 PE Alpha 0.1.3 至 0.8.1 首次出生和使用世界出生点重生时可能卡进方块的问题。先加载出生区块，再沿原 X/Z 检查玩家站立所需空间，逐格上移至能容纳玩家的位置。初始视角沿用预设。0.1.3 种子 999 的两份原版存档在 (128, 128) 均记录共享出生 Y=64，该列草方块位于 Y=84，脚底应落在 Y=85。

手机端观察：0.7.6 先前的地形对照漏填了种子，已撤回。早期植被暂未发现已确认的同种子偏差。0.6.1 手机端建图崩溃，缺少实机对照。植被偏差后续排查从 0.9.x 起。

Build 3.11 为新建的八个 PE Alpha 有限预设接入对应的生成流程：0.1.3、0.2.2、0.3.3、0.4.0、0.5.0、0.6.1、0.7.6、0.8.1。各版原始 Android ARM 库分别测试了基础地形和表层，四个种子共 80 个区块，密度、基础方块、沙漠与结冰海岸样本逐项一致。八版共用已验证的密度与表层实现。默认边界覆盖 X、Z 各 0 至 255 格。Build 3.10 保存的旧世界继续使用创建时的基础地形。

有限世界装饰保留版本差异，包括 0.2.2、0.3.3 普通树使用的原木材质，0.5.0 前后的蘑菇生存条件，以及 0.7.6 起黏土脉的计算精度。每版验证了原版矿脉形状、矿物阶段的候选坐标与随机状态。历史地质设置下，相邻区块的矿脉按 PE 的生成顺序覆盖。地形生成时，有限边界阻挡树冠和泉眼。默认流程每个装饰区块尝试 50 次水泉和 20 次岩浆泉。独立椭球湖泊、岩浆湖与洞穴雕刻均未接入这八版的原生区块流程；水面与地形空腔仍可自然形成。

0.1.3 种子 999 的最终 Fabric 服务端存档对照覆盖 PE 存档中全部 255 个可读区块。Y=0 至 127 的 8,355,840 个位置经 PE 方块 ID 映射对比均一致，另行检查的原木与树叶种类也一致。此项对照未覆盖光照、实体或所有存档元数据。其他七版验证了 ARM 样本，尚无对应的完整 PE 存档对照。

修改 Java Edition Contents Provider 或 Bedrock Exclusive Features Provider 的设置后，World Preset 按钮显示青色 Custom。选择预设或将设置调回该预设默认值时恢复黄色版本名。

Build 3.10 修复开启 JE 1.18 深地形时的首次出生与普通重生。先加载出生区块，再按实际地表选取高度；个人重生点优先。

0.1.3 至 0.8.1 的八个早期预设按 PE 装饰顺序生成树、花、蘑菇、甘蔗、仙人掌、泉眼和积雪。黏土和矿脉消耗的随机数参与后续植被选点。这些版本没有独立的高草撒点和椭球湖泊步骤。早期青色玫瑰使用单独的方块和新绘制的纹理。早期基础地形尚未逐版本复刻。

0.9.5 和 0.10.2 的无限预设恢复低于 Y=60 的岩浆湖候选点。0.9 至 0.11 的湖泊仍按同一区块紧接地形生成时的线程随机状态重建。0.16.5 Old 沿用 0.16.2 的实现。种子 999 和固定随机输入下对照了原版 ARM 的树形、矿脉、植被撒点、湖泊候选与湖形。完整手机存档的逐方块一致性仍待验证。

0.9 至 0.16 的装饰修正了分版本的撒点轴顺序、部分植被的高度、基质和光照判定，以及后期甘蔗的水平范围。九份 ARM 样本中，种子 999 下七类植被的 2,358 个候选坐标逐一吻合。有限世界和无限世界保留各自的原版草丛规则。实际地形、前序装饰和相邻区块的生成顺序仍会影响最终密度，手机同坐标的草丛数量留待对照。

Build 3.9 在 Java Edition Contents Provider 中加入 1.18 的十个开关与 1.19 的三个开关，全部 PE Alpha 预设默认关闭。可分别配置噪声洞穴、含水层、繁茂洞穴、溶洞、负高度地形、矿石分布、大型铜铁矿脉、山地群系与山地地形，以及深暗之域、远古城市与红树林沼泽。启用后在 PE 地形上组合 Java 生成器。旧版 JSON 可继续导入。

Build 3.8 修复早期 PE 气候群系的自然选树。默认雨林与稀树草原选普通橡树，森林保留桦树分支，针叶林保留两种普通针叶树。JE 设置中的 1.7.x 分组控制金合欢、深色橡树、巨型松树与巨型云杉，Adventure Update Part II 分组控制普通和巨型丛林树。六项对 0.9 以前预设默认关闭，对 0.9.5 起预设默认允许。手动扩展早期群系时，深色橡树可出现在森林和季节林，巨型针叶树可出现在针叶林。普通丛林树开关同时控制使用丛林原木的矮灌木。设置影响新区块的自然生成。

Build 3.8 移植 Moderner Beta 的 Preview biomes。宽幅地图使用当前 PE 种子、群系设置与有限世界边界，支持拖动、缩放、网格、比例尺、群系提示以及导出地图 PNG。有限世界初始视图以边界中心定位。

Build 3.7 新增 0.1.3、0.2.2、0.3.3、0.4.0、0.5.0、0.6.1、0.7.6、0.8.1 的有限预设，共用十种 PE Alpha 群系及单精度温湿度采样。0.9 之前的预设默认开启 Use Pre-0.9.x Biomes。群系决定地表与装饰使用的兼容类型，早期地形密度、地表装饰、实体与出生点尚未逐版本复刻。
Allow Nether Portal 在所有 Old 预设以及 0.12 之前的预设默认关闭。Finite World 控制边界生成、下界大小同步和三个边界输入框；关闭后保留输入值。新增自选的 JE 1.17 铜矿、紫水晶洞、凝灰岩团块、深板岩团块和发光地衣，使用 Java 的特征生成器及 1.17.1 放置参数。

Build 3.6 新增 0.9.5、0.10.2 无限世界和 0.9.5 至 0.16.5 的版本化 Old 预设。0.16.5 Finite 使用 0.16.2 系列的生成规则。种子 999 在 0.9.5、0.10.2 两个 ARM 原版、两种世界类型中分别对照了 6,144 个群系采样。两版各抽取三个无限区块，比对密度符号和普通地表方块。早期基岩逐层取样，恶地的额外金矿和地表矿井从 0.10.2 预设起启用。

选择世界
创建世界时选择 Bedrock Edition，打开自定义中的 World Preset。无限分类从 0.9.5 到 0.16.2，Finite 分类另有 0.16.5。服务端默认预设 ID 为 pe_worldgen:mcpe_alpha，具体版本可使用 pe_worldgen:pe_095_infinite 或 pe_worldgen:pe_0102_old 等 ID。旧存档省略 pe_version 时按 0.11.1 读取。

主世界
五个新版本共用经 ARM 对照的群系层和密度链。0.14 起切换二维地表噪声，0.15 起切换偏移初始化及洞穴起点取样顺序。新预设含恶地彩层与石柱、巨型针叶林、沼泽、山地和破碎热带草原的专属地表。世界建筑范围 Y=-64 至 319，PE 地形 Y=0 至 127。旧世界初始边界为 256×256 格。
0.13.2 起加入沙漠神殿，0.14.3 起加入女巫小屋，0.15.10 起加入丛林神庙、冰原村庄和村庄地方用材，0.16.2 加入海底神殿。主菜单的“生成结构”设置控制建筑。种子 999 的沙漠神殿、女巫小屋和丛林神庙可分别在 (720,-800)、(-1840,544)、(-3232,-3360) 附近观察。0.16.2 的海底神殿可在 (744,39,-1224) 附近观察。

关闭 1.13.x 海洋群系时，PE 海洋统一显示 Ocean。各项结构和植被使用各自的开关。1.14 以 PE 候选位置生成 JE 村庄，启用哨站、竹林和竹林丘陵。1.15 为合适的橡树、白桦树附加蜂巢，并在巨型针叶林生成甜浆果。1.16 切换到 1.21.11 原生下界生成器、群系及结构。允许创建下界传送门的开关已移至 Bedrock Exclusive Features Provider。

核对范围与已知差异
种子 999 对照五个 Android ARMv7 发布版。每版 6,144 个原始及细化群系值一致，出生锚点 (60,128,8)。共 6,375 个密度值的正负号一致。普通地表与基岩、纯石样本上的洞穴各比对 491,520 个方块。以 PE 0.12.3 下界三个区块核对地形、地表和洞穴，98,304 个方块一致。一个下界要塞的 144 个部件与原版布局一致。
各版本的群系、建筑和装饰仍可能有局部偏差。0.12、0.13 的部分恶地分层，季节性积雪、植被细部、女巫炼药锅内容和稀有箱子附魔书尚有差异。跨区块装饰受生成顺序影响，动态流体由 Java 接管。0.16 的海底神殿以固定的 Android 初始洗牌状态重建房间，再用 Java 沿用的旧式房间组件放置。PE 下界要塞的自然专属刷怪及原版 /locate 查询尚未接入，烈焰人刷怪笼已接入。现有存档已生成的区块保留原貌。

历史
Build 2.6 修复了 Fabric Loader 0.18.4 搭配 MixinExtras 0.5.0 时 World 在启动阶段转换失败的问题。

Build 2.5 的两级预设列表采用 Moderner Beta 的图文条目，运行时读取 Programmer Art 图标。有限地图按 MB 的边界谓词注入虚空群系，按 PE 地图锚点定位，边缘余量为 0。兼容 C2ME 的群系采样优化。

Build 2.4 的主世界可在 Y=-64 至 319 建造。PE 地形维持 Y=0 至 127；两侧在生成时为空气。自定义界面增加分类预设、生物群系预览、快速导入导出和数据包导出。

Build 2.3 在新建 PE 世界中统一地形、装饰和结构选址使用的丘陵群系随机状态。修正稀疏群系种树抽样、PE 地表高度查询和湖壁材料判定。铁匠铺和泉水在生成时处理液体更新。旧存档沿用原先持久化的结构选址，已有区块保留原貌。

有限世界的主世界使用边长 256 的 Java 原版世界边界，范围外新生成的区块为空气，全高度使用 minecraft:the_void。2.2 起新建的有限世界以出生区块确定范围，更早的世界以原点确定范围。以前生成在外围的屏障区块会保留。
