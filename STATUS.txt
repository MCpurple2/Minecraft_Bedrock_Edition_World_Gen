Bedrock Edition World Generator Build 3.5 · IWBUMS
Minecraft Java Edition 1.21.11 · Fabric

Build 3.5 aligns the standard overworld ore vein sizes from Alpha 0.12.3, lake ellipsoid centers and ore coordinate rounding from 0.13.2, tree soil preparation from 0.14.3, and ore and plant offset draw order from 0.15.10. Tall grass in 0.15.10 and 0.16.2 uses the original input height for scattering. The 0.11.1 common tree canopy uses the native block replacement table. Seed 999 comparisons covered individual features on controlled terrain. Full populated chunks can still differ from PE.

Build 3.4 将铅笔编辑器的配置按更新版本排列，旧式村庄键为 legacy_villages。可粘贴 Build 3.3 的编辑器 JSON。

新生成的旧式村庄铁匠铺保留槽内两个岩浆源，建造期间不立即推进岩浆扩散。

选择世界
在“世界类型”选择 Pocket Edition Alpha，打开“自定义”→ World Preset → Pocket Edition Alpha，选择无限预设 0.11.1、0.12.3、0.13.2、0.14.3、0.15.10 或 0.16.2。Pocket Edition Alpha Finite 提供 0.11.1 的旧世界。服务端 level-type 可用 pe_worldgen:mcpe_alpha（默认 0.11.1 无限）或 pe_worldgen:pe_0123_infinite、pe_worldgen:pe_0132_infinite、pe_worldgen:pe_0143_infinite、pe_worldgen:pe_01510_infinite、pe_worldgen:pe_0162_infinite。旧存档中省略 pe_version 的区块生成器按 0.11.1 读取。

主世界
五个新版本共用经 ARM 对照的群系层和密度链。0.14 起切换二维地表噪声，0.15 起切换偏移初始化及洞穴起点取样顺序。新预设含恶地彩层与石柱、巨型针叶林、沼泽、山地和破碎热带草原的专属地表。世界建筑范围 Y=-64 至 319，PE 地形 Y=0 至 127。旧世界的 256×256 边界范围外为空气和虚空群系。
0.13.2 起加入沙漠神殿，0.14.3 起加入女巫小屋，0.15.10 起加入丛林神庙、冰原村庄和村庄地方用材，0.16.2 加入海底神殿。主菜单的“生成结构”设置控制建筑。种子 999 的沙漠神殿、女巫小屋和丛林神庙可分别在 (720,-800)、(-1840,544)、(-3232,-3360) 附近观察。0.16.2 的海底神殿可在 (744,39,-1224) 附近观察。

Java Edition Contents Provider → Settings
关闭 1.13.x 海洋群系时，PE 海洋统一显示 Ocean。各项结构和植被使用各自的开关。1.14 以 PE 候选位置生成 JE 村庄，启用哨站、竹林和竹林丘陵。1.15 为合适的橡树、白桦树附加蜂巢，并在巨型针叶林生成甜浆果。1.16 切换到 1.21.11 原生下界生成器、群系及结构。允许创建下界传送门是独立选项，有限世界默认关闭，无限世界默认开启。
关闭 1.16 时使用 PE 0.12.3 下界地形、洞穴、矿脉、装饰及下界要塞，全境下界荒地。种子 999 可在 (-702,59,642) 附近观察要塞。

核对范围与已知差异
种子 999 对照五个 Android ARMv7 发布版。每版 6,144 个原始及细化群系值一致，出生锚点 (60,128,8)。共 6,375 个密度值的正负号一致。普通地表与基岩、纯石样本上的洞穴各比对 491,520 个方块。以 PE 0.12.3 下界三个区块核对地形、地表和洞穴，98,304 个方块一致。一个下界要塞的 144 个部件与原版布局一致。
各版本的群系、建筑和装饰仍可能有局部偏差。0.12、0.13 的部分恶地分层，季节性积雪、植被细部、女巫炼药锅内容和稀有箱子附魔书尚有差异。跨区块装饰受生成顺序影响，动态流体由 Java 接管。0.16 的海底神殿以固定的 Android 初始洗牌状态重建房间，再用 Java 沿用的旧式房间组件放置。PE 下界要塞的自然专属刷怪及原版 /locate 查询尚未接入，烈焰人刷怪笼已接入。现有存档已生成的区块保留原貌。

历史
Build 2.6 修复了 Fabric Loader 0.18.4 搭配 MixinExtras 0.5.0 时 World 在启动阶段转换失败的问题。

Build 2.5 的两级预设列表采用 Moderner Beta 的图文条目，运行时读取 Programmer Art 图标。有限地图按 MB 的边界谓词注入虚空群系，按 PE 地图锚点定位，边缘余量为 0。兼容 C2ME 的群系采样优化。

Build 2.4 的主世界可在 Y=-64 至 319 建造。PE 地形维持 Y=0 至 127；两侧在生成时为空气。自定义界面增加分类预设、生物群系预览、快速导入导出和数据包导出。

Build 2.3 在新建 PE 世界中统一地形、装饰和结构选址使用的丘陵群系随机状态。修正稀疏群系种树抽样、PE 地表高度查询和湖壁材料判定。铁匠铺和泉水在生成时处理液体更新。旧存档沿用原先持久化的结构选址，已有区块保留原貌。

有限世界的主世界使用边长 256 的 Java 原版世界边界，范围外新生成的区块为空气，全高度使用 minecraft:the_void。2.2 起新建的有限世界以出生区块确定范围，更早的世界以原点确定范围。以前生成在外围的屏障区块会保留。

构建
Java 21、Fabric Loom、Gradle wrapper。Windows 运行 gradlew.bat build。发行包在 build/libs。
