Pocket Edition Alpha Build 2.0 IWBUMS
Minecraft Java 1.21.11 · Fabric · PE Alpha 0.11.1 主世界

安装与创建
将本版 pe-worldgen JAR 和适用于 1.21.11 的 Fabric API 放入 mods 文件夹，替换此前的 pe-worldgen JAR。
创建新世界时，世界类型选择 Pocket Edition Alpha。相邻的“自定义”按钮可选择 PE 0.11.1 和无限世界或旧世界（256×256）。已有完整区块保留原貌。
服务端统一入口为 pe_worldgen:mcpe_alpha（默认无限），另支持 pe_worldgen:pe_0111_old 和 pe_worldgen:pe_0111_infinite。生成村庄、废弃矿井和要塞需要开启生成结构。

已接入的 PE 算法
· MT19937、群系层链、噪声密度、通用地表、基岩、海平面与无限世界洞穴。
· 群系装饰、树种与树形选择、倒木、巨大蘑菇、矿脉、湖泊和泉水。
· 旧式村庄的选址、道路、水井、住房、农田、铁匠铺、箱子、村民和沙漠用材。
· 无限世界的废弃矿井、地下刷怪房和要塞，含图书馆、传送门房间和蠹虫刷怪笼。
· 在 Java 主世界直接放置这些 PE 方块，跨区块保留建筑状态。地表装饰和建筑布局使用 PE 0.11.1 规则。村民的外观和交易由 Java 实体系统提供。

可复现位置
种子 67，无限世界，生成结构开启。旧村庄的水井在 X=52、Z=20 一带；要塞传送门框围绕 X=-5499、Y=15、Z=-1780。两处均已从实际生成的 Java 版服务端存档读取。旧世界也已实际生成、保存并读到树叶、村道和农田。

对照范围
原始 Android ARMv7 库 versionCode 740110102。树木和巨大蘑菇 90 组固定地形样例的位置、方块 ID、附加值及下一随机数与原生一致。村庄选址 925 组和布局 16 组通过；要塞布局 8 个种子、1487 个部件通过。矿井布局 5 个种子、564 个部件通过。测试样例与方法见相邻的 pe-worldgen-analysis-0.11.1。

已知差异
· 大范围完整存档尚未进行同种子逐方块比对。旧世界边界固定在 X/Z=-128..127，PE 的出生区块搜索和相对偏移仍待移植。
· Mesa、Swamp 等专属地表、部分方块材质与光照判断、树叶颜色，以及泉水首次流动后的排队更新仍有差异。雪层、藤蔓、湖泊和植被会受这些差异影响。
· PE 的跨区块装饰顺序和湖泊使用的线程随机状态可能随调度变化；不同的加载次序可能影响树与建筑相邻处的方块。
· 下界和末地沿用 Java 原版。客户端菜单与实际游玩由用户检查。

构建
Java 21、Fabric Loom、Gradle wrapper。Windows 运行 gradlew.bat build。发行包在 build/libs。
