Pocket Edition World Generator · Build 2.6 IWBUMS
Minecraft Java 1.21.11 · Fabric · PE Alpha 0.11.1 主世界

Build 2.6 修复了 Fabric Loader 0.18.4 搭配 MixinExtras 0.5.0 时 World 在启动阶段转换失败的问题。

Build 2.5 的两级预设列表采用 Moderner Beta 的图文条目，运行时读取 Programmer Art 图标。有限地图按 MB 的边界谓词注入虚空群系，按 PE 地图锚点定位，边缘余量为 0。兼容 C2ME 的群系采样优化。

Build 2.4 的主世界可在 Y=-64 至 319 建造。PE 地形维持 Y=0 至 127；两侧在生成时为空气。自定义界面增加分类预设、生物群系预览、快速导入导出和数据包导出。

Build 2.3 在新建 PE 世界中统一地形、装饰和结构选址使用的丘陵群系随机状态。修正稀疏群系种树抽样、PE 地表高度查询和湖壁材料判定。铁匠铺和泉水在生成时处理液体更新。旧存档沿用原先持久化的结构选址，已有区块保留原貌。

有限世界的主世界使用边长 256 的 Java 原版世界边界，范围外新生成的区块为空气，全高度使用 minecraft:the_void。2.2 起新建的有限世界以出生区块确定范围，更早的世界以原点确定范围。以前生成在外围的屏障区块会保留。

安装与创建
将本版 pe-worldgen JAR 和适用于 1.21.11 的 Fabric API 放入 mods 文件夹，替换此前的 pe-worldgen JAR。
创建新世界时，世界类型选择 Pocket Edition Alpha。相邻的“自定义”按钮可选择 PE 0.11.1 和无限世界或旧世界（256×256）。已有完整区块保留原貌。
服务端统一入口为 pe_worldgen:mcpe_alpha（默认无限），另支持 pe_worldgen:pe_0111_old 和 pe_worldgen:pe_0111_infinite。生成村庄、废弃矿井和要塞需要开启生成结构。

已接入的 PE 算法
· MT19937、群系层链、噪声密度、通用地表、基岩、海平面与无限世界洞穴。
· 群系装饰、树种与树形选择、倒木、巨大蘑菇、矿脉、湖泊和泉水。
· 旧式村庄的选址、道路、水井、住房、农田、铁匠铺、箱子、村民和沙漠用材。
· 无限世界的废弃矿井、地下刷怪房和要塞，含图书馆、传送门房间和蠹虫刷怪笼。
· 在 Java 主世界直接放置这些 PE 方块，跨区块保留建筑状态。地表装饰和建筑布局使用 PE 0.11.1 规则。村民的外观和交易由 Java 实体系统提供。

可复现位置
无限世界 mimi（3351608）的三个要塞起始区块与 PE 0.11.1 ARM 一致，依次为 (-17,-75)、(86,2)、(42,-95)。服务端存档中水井 X=1380、Z=36 一列的井底是 Y=56 的圆石，Y=55 为石砖，Y=54 进入要塞内部。
无限世界 999 的铁匠铺在 (98,68,29) 出现一格等级 6 的外溢岩浆。其有限世界的边界中心为 X=112、Z=16，东侧 X=239 为地形最后一列，X=240 开始为虚空。
种子 999 的原版 PE ARM 世界出生点与 Fabric 服务端存档一致。无限世界锚点 (60,128,8)，服务端首次落脚 (60.5,68,8.5)；有限世界锚点 (112,128,20)，服务端首次落脚 (112.5,67,20.5)。两者首次朝向均为正南、平视。

对照范围
原始 Android ARMv7 库 versionCode 740110102。树木和巨大蘑菇 90 组固定地形样例的位置、方块 ID、附加值及下一随机数与原生一致。村庄选址 925 组和布局 16 组通过；要塞布局 8 个种子、1487 个部件通过。矿井布局 5 个种子、564 个部件通过。测试样例与方法见相邻的 pe-worldgen-analysis-0.11.1。

已知差异
· PE 的出生搜索在首行边缘读到栈上残留值，个别种子的锚点可能受运行环境影响。实际落脚高度取决于装饰后的方块与碰撞形状，目前使用 Java 方块形状。完整存档尚未进行大范围逐方块比对。
· Mesa、Swamp 等专属地表、部分方块材质与光照判断、树叶颜色及复杂液体交界仍有差异。世界生成完成后的实时流体更新由 Java 接管。
· PE 的跨区块装饰顺序和湖泊使用的线程随机状态可能随调度变化；不同的加载次序可能影响树与建筑相邻处的方块。
· 下界和末地沿用 Java 原版。客户端菜单与实际游玩由用户检查。

构建
Java 21、Fabric Loom、Gradle wrapper。Windows 运行 gradlew.bat build。发行包在 build/libs。
